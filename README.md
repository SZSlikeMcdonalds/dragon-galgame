# 《今夜，谁来守城》

一个无需安装、可以离线游玩的中文校园 Galgame 原型。

这是非官方同人原型，不含《率土之滨》原游戏图片、音频或代码素材。

## 开始游戏

双击 `index.html`，用任意现代浏览器打开即可。

## 操作

- 单击对话框、按 `Enter` 或空格：推进剧情
- “自动”：自动播放或停止
- “瞬显”：立即显示当前整句台词
- “羁绊”：查看十位角色的好感度和支线完成情况
- “存档 / 读档”：使用浏览器本地存储保存和恢复进度
- 至少完成三条角色支线后，可进入最终修罗场

## 内容

- 序章与十条可自由选择的角色支线
- 知恩、寒林、稻花香、武松、湫澄、胖虎、话事人、三米、嫩油条、年糕
- 湫澄专属奶蛙表情包桥段
- 三种开放式结局
- 响应式界面，电脑和手机浏览器均可游玩

所有登场角色均为年满 20 岁的成年人。
